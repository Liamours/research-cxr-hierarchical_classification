this is an equation folder

one file per equation (or a small tightly-related group), plain text or LaTeX math, not prose

naming matches the sections convention: "{section}-{slug}.md", e.g. "2.2-otsu-variance.md"

in the section md, an equation must be mentioned in prose before its `<equations/...>` placement line, not just captioned after

there is "temp" folder for temporary files like notes, or images to ocr, and all that
