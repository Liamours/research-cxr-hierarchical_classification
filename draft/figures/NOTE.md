this is a figure folder

only png with high dpi in here. some figure rules:
1. use times new roman font
2. no need for descriptions, just the figure itself, we place the description in the paper later
3. palette in virdis, but no need for colorbar, other palette is prioritized if stated
4. in the section md, a figure must be mentioned in prose before its `<figures/...>` placement line, not just captioned after

there is "temp" folder for temporary files like md, or images to ocr, and all that
