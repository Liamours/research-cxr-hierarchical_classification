this is an algorithm folder

one file per algorithm: numbered pseudocode steps (stages, inputs, params, output), plain text or md, not prose

naming matches the sections convention: "{section}-{slug}.md", e.g. "2.2-modified-otsu.md"

in the section md, an algorithm must be mentioned in prose before its `<algorithms/...>` placement line, not just captioned after

there is "temp" folder for temporary files like notes, or images to ocr, and all that
